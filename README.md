# Sidework Codex 0.10.0

macOS용 Electron 기반 실험적 AI 브라우저입니다. 일반 탐색과 앱 소유 에이전트 작업 공간을 분리하고, 로컬의 공식 Codex CLI를 모델 제공자로 사용합니다. Aside의 공개 워크플로를 참고한 독립 구현이며 원본 엔진·비공개 API·브랜드 자산을 가져온 제품이 아닙니다. 해당 서비스와 제휴 관계가 없습니다.

## 상태와 한계

- 개발 중인 소스 공개 스냅샷입니다. 완성된 범용 자율 브라우저나 보안 인증 제품이 아닙니다.
- 앱 소유 웹뷰의 탐색·관찰·입력·스크롤, 목표 기반 작업 공간과 정책 검증을 구현합니다.
- Google/Naver 자동 검색은 실험적입니다. 사이트 변경·동적 문서·CAPTCHA 등으로 중단될 수 있으며 안정적인 실사이트 완주를 보장하지 않습니다.
- 로그인·결제·업로드·동의·CAPTCHA 처리를 자동으로 우회하는 기능은 제공하지 않습니다.
- 공개 배포본에는 개인 계정, CLI 인증정보, 기존 브라우저 세션, 실제 작업 로그·영상 및 앱 바이너리를 포함하지 않습니다.
- macOS Apple Silicon을 주 개발 대상으로 합니다. Developer ID 서명·공증·자동 업데이트·다른 물리 기기에서의 동작은 검증되지 않았습니다.

## 개발

검증 환경은 Node.js 22.23.0 / npm 10.9.8입니다. 잠금 파일을 사용해 의존성을 설치하세요.

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run build
npm start
```

개발 서버는 `npm run dev`로 실행합니다. macOS 앱 폴더 패키지는 `npm run package:mac`으로 생성하며 출력 경로는 `package.json`의 `build.directories.output`을 참고하세요. 로컬 ad-hoc 서명은 공증이 아닙니다.

테스트·타입 검사·lint·빌드는 모델 계정을 요구하지 않는 경로입니다. 앱 실행에는 Electron 바이너리가 필요합니다. CI 등에서 모델을 사용하지 않고 위 검사만 수행할 때는 `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci`로 바이너리 다운로드를 생략할 수 있습니다.

## 공개 스냅샷 검증

공개 경계에서 새로 의존성을 설치한 뒤 단위 테스트 **667개 통과 / 실패 0개**, 타입 검사·lint·빌드 통과를 확인했습니다. 이는 실제 사이트의 모델 작업 성공, 계정 연결, 다른 기기 호환성 또는 보안 인증을 의미하지 않습니다.

## 모델 제공자

실제 AI 작업에는 별도로 설치하고 로그인한 공식 Codex CLI가 필요합니다. 인증정보를 저장소에 넣지 마세요. 실행 파일은 PATH에서 탐색하거나 `SIDEWORK_CODEX_PATH`로 지정합니다. 모델 계정·네트워크·사용량 비용은 사용자 환경에 따릅니다.

**모델을 사용하면 선택된 페이지에서 관찰한 내용과 작업 요청이 외부 제공자에 전달될 수 있습니다.** 비밀정보가 있는 페이지에서 사용하지 마세요. 민감 입력 마스킹은 모든 페이지 본문의 개인정보를 식별한다는 보장이 아닙니다.

## 데이터와 권한

- 개인 Chrome 프로필을 가져오지 않고 앱 소유 데이터 경로를 사용합니다.
- 웹페이지에는 Node나 신뢰 IPC를 제공하지 않습니다.
- 모델 제안은 실행 권한이 아닙니다. 메인 프로세스가 대상 문서·프로필·revision·권한·취소 상태 등을 확인합니다.
- 결과 불명 상태는 성공과 구분하며, 불명 변경을 자동 재시도하지 않습니다.
- 일반 검색 호환성을 위한 전용 경로가 민감 작업에 대한 일괄 허가를 의미하지 않습니다.

## 저장소 구성

- `src/desktop`: Electron 메인 프로세스, 소유 웹뷰와 정책 집행
- `src/core`: 작업 실행과 상태 저장
- `src/provider`: Codex CLI 연동
- `src/renderer`: React UI
- `tests`: 계정 없이 실행하는 회귀 테스트
- `scripts`: 빌드·개발 및 선택적 QA 도구

`scripts`의 네이티브/실모델 QA는 별도 opt-in 도구입니다. 기본 단위 테스트의 일부가 아니며, 과거 UI를 대상으로 한 도구도 포함합니다. 이를 현재 기능의 완료 증거로 사용하지 마세요. 일부 도구는 먼저 `mkdir -p qa`가 필요하고, `computer-grid-qa.mjs`의 자원 측정에는 `psutil`이 설치된 Python(`SIDEWORK_PYTHON`, 기본 `python3`)이 필요합니다. 실제 모델 QA는 로그인과 사용량을 요구할 수 있습니다.

개인 운영 문서와 QA 캡처는 공개 경계에서 제외했으며 기존 Git 이력 대신 정리된 단일 소스 스냅샷을 게시합니다. 제품 의도와 UI 방향은 `PRODUCT.md`, `DESIGN.md`를 참고하세요.
